# mtm6302-final-huss0329Gotta Scalp Em’ All – Pokémon Game

Project Description

Gotta Scalp Em’ All is a Pokémon-inspired card collection game where players can purchase and open Pokémon packs, discover random Pokémon cards, build their collection, and sell cards to earn coins. The goal is to collect different Pokémon while managing the available coins.

Features

* Open Pokémon Packs: Spend coins to open packs and receive randomly selected Pokémon cards.
* Collect Pokémon: Build a personal collection of Pokémon cards.
* View Collection: View collected Pokémon, including their names, images, types, and rarities.
* Sell Pokémon: Sell collected cards to earn coins.
* Coin Balance: Keep track of available coins and spending.
* Save Progress: Use Local Storage to save the player’s coins and collected Pokémon.
* Reset Game: Clear saved progress and restart the game with the original balance.
* Responsive Design: Support both mobile and desktop screen sizes.
* Game Feedback: Display success and error messages when players perform actions.

Technologies Used

* HTML5 – Application structure.
* CSS3 – Styling and responsive layouts.
* JavaScript – Game functionality, random card selection, calculations, and interactions.
* Local Storage – Saving and restoring player progress.

How to Play

1. Open the application in your browser.
2. Start with the initial amount of 100 coins.
3. Click the Open Pack button to purchase a Pokémon pack.
4. Discover a randomly selected Pokémon card.
5. View your collected Pokémon in the collection section.
6. Sell unwanted Pokémon cards to earn more coins.
7. Continue opening packs and building your collection.

Data Management

The application uses a predefined JavaScript array containing Pokémon information, including names, images, types, rarities, and values.

Local Storage uses the project-specific key:

pokemonGameSave

The player’s coin balance and Pokémon collection are saved automatically whenever game progress changes. Previously saved information is restored when the application is reopened.

No external API or database is required.

Error Handling

The application provides feedback for different situations, including:

* Insufficient coins when attempting to open a pack.
* Empty Pokémon collection.
* Successful pack openings.
* Successful card sales.
* Confirmation before resetting saved progress.

Installation and Setup

1. Clone or download the project repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Start playing!

No additional installation or external database is required.
